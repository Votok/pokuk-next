# Domain docs

This repository uses a single context. Read the root `GLOSSARY.md` and
relevant ADRs in `docs/adr/` before exploring the affected area. If these
files do not exist yet, proceed.

Use glossary terms in specs, issues, tests, and design discussions.
Add terms as the domain vocabulary is agreed. Record approved,
significant architecture decisions in numbered files under `docs/adr/`
using `NNNN-short-title.md`. Explain the context, decision, and
consequences. Surface conflicts with existing ADRs explicitly.
